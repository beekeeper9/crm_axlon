# Дизайн-система

Образ: «точный инструмент» с акцентом на результат. Спокойный холодный интерфейс, один выразительный брендовый цвет, статусы со строгими значениями, высокая плотность информации без визуального шума.

Источник правды — токены в `app/globals.css`. В компонентах используем только токены (`bg-primary`, `text-success`, `border-border`), а не произвольные цвета.

## Цвет

| Токен | Назначение |
|-------|-----------|
| `background` | Фон приложения: холодный светло-серый, чуть темнее карточек |
| `card` | Карточки и виджеты (белые) |
| `foreground` / `muted-foreground` | Основной текст / вторичный текст и подписи |
| `primary` | Бренд, глубокий кобальт. Главные действия, активный пункт, основной ряд графиков |
| `accent` | Лёгкая подложка брендового цвета: наведение, выделение |
| `border`, `input` | Разделители и поля |

### Статусы — одинаковый смысл во всём продукте

| Тон | Токен | Значение |
|-----|-------|----------|
| success | `--success` (зелёный) | Цель достигается, всё в порядке, рост |
| warning | `--warning` (янтарный) | Риск, требует внимания, узкое место |
| danger | `--destructive` (красный) | Отставание, просрочка, ошибка, удаление |
| info | `--info` (= primary) | Нейтральная информация |
| neutral | `muted` | Счётчики, служебные метки |

Статус никогда не передаётся только цветом: рядом всегда есть текст или иконка (`StatusBadge`, `TrendIndicator`).
Подложки статусов — сам цвет с прозрачностью 8–12 % (`bg-success/10`).

### Графики

`chart-1` — основной ряд (кобальт), `chart-2` — бирюзовый, `chart-3` — янтарный, `chart-4` — фиолетовый, `chart-5` — серый: план, ориентиры, сравнение. План на графиках рисуется пунктиром `chart-5`, факт — сплошной линией `chart-1` с лёгкой заливкой.

## Типографика

- Шрифт интерфейса — **Inter** (латиница и кириллица), моноширинный — Geist Mono.
- Включены цифры одинаковой ширины (`tnum`): колонки чисел ровные, значения не «прыгают».
- Базовый размер интерфейса — 14 px (`text-sm`); подписи и вторичные данные — 12 px (`text-xs`).
- Заголовок страницы — `text-xl font-semibold tracking-tight`; заголовок виджета — `text-sm font-semibold`; значение KPI — `text-2xl font-semibold tracking-tight`.

## Форма и отступы

- Базовый радиус `--radius: 0.5rem`: карточки `rounded-xl`, кнопки и поля `rounded-lg`, мелкие элементы `rounded-md`.
- Карточки — белые, тонкая обводка (`ring-1 ring-foreground/10`), без теней. Глубину задаёт контраст фона и карточки.
- Сетка отступов Tailwind (шаг 4 px). Между виджетами — `gap-4`, между блоками страницы — `space-y-6`, внутри карточки — 16 px.
- Ширина контента ограничена `max-w-screen-2xl`; поля страницы — 16 / 24 / 32 px на телефоне / планшете / десктопе.

## Каркас и навигация

- Слева — боковое меню с группами «Работа» и «Управление». На десктопе сворачивается до иконок (с подсказками), горячая клавиша ⌘/Ctrl + B. На телефоне открывается поверх страницы и закрывается после перехода.
- Сверху — панель с названием раздела и меткой «Демо-данные», пока backend не подключён.
- Пункты меню скрываются по правам роли. Это только отображение, доступ проверяет backend.

## Виджеты и состояния

| Состояние | Компонент | Правило |
|-----------|-----------|---------|
| Загрузка | `WidgetSkeleton`, `KpiCardSkeleton`, `loading.tsx` | Скелетон той же высоты, что и контент; заголовок виджета виден сразу |
| Пусто | `EmptyState` | Иконка, понятный заголовок и что сделать дальше |
| Ошибка | `ErrorState` + `WidgetErrorBoundary` | Сообщение без технических деталей и кнопка «Повторить»; падает только этот виджет |
| Раздел в разработке | `UpcomingSection` | Честно сообщает, что раздела ещё нет |

Рамка любого виджета — `WidgetCard`: заголовок, описание, действие справа, одинаковые отступы и высота в ряду.

## Таблицы

- Шапка — `text-muted-foreground`, строки с разделителями, числа выровнены вправо.
- Вторичное значение под основным — `text-xs text-muted-foreground` (например, «из 2 400 000 сом»).
- Широкие таблицы на узких экранах прокручиваются горизонтально внутри карточки, а не всей страницей.

## Числа и даты

Только через `lib/format.ts`: `1 250 000 сом`, `23,1 %`, `−1,7 п. п.`, `27 окт.`, `14:30` (часовой пояс компании).

## Адаптивность

Приоритет — десктоп. Двенадцатиколоночная сетка виджетов включается с 1280 px. Ниже виджеты идут в одну колонку, KPI — по 2 в ряд (от 640 px) или по одному.

## Тёмная тема

Токены тёмной темы подготовлены (`.dark`), но переключатель не включён. Это решение не утверждено.
